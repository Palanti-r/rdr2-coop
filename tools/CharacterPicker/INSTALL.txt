RDR2 Co-op Settings for Windows
===============================

VERSION.txt identifies the upstream Windows installer bundled with this
fork. The bundle includes the standard loader, its .NET runtime and
support libraries, the legacy build, and the settings app. The settings
app uses .NET Framework 4.8.

Install
-------
1. Close the game and extract this ZIP outside the game folder. Back up
   your existing saves and co-op settings if you're updating.
2. Open the extracted RDR2-Coop folder and run RDR2CoopSetup.exe. Follow
   its prompts. The installer fetches ScriptHookRDR2 if you need it.
3. Open RDR2CoopCharacterPicker.exe from the same extracted folder and
   browse to scripts/RDR2Coop.ini inside your game installation.

For manual installation, see README-PLAYERS.txt. If you already use the
legacy loader, its DLL is under shdn/scripts. Keep only one co-op loader
active.

Choose Guest or Host
--------------------
Open Connection, pick Guest to join a room or Host to start one, then
enter its connection details. Click Save settings and restart RDR2.
The app remembers both profiles.

In Guest mode, open Character, choose a preset, and click Apply character.
Return to Story Mode and stand on foot as a guest in free roam. Changing
presets works during play.

If the menu doesn't open
------------------------
Open Diagnostics, choose the folder containing RDR2.exe, and click
Check files and logs. Enable debug logging and restart RDR2 to record
menu shortcuts and character messages. Try the shortcut in Story Mode,
then check Recent logs in the picker.

To keep using the fork's guest character picker, install updates from this
fork. The in-game upstream update installs the official mod DLL.

More instructions:
https://github.com/Palanti-r/rdr2-coop/tree/master/tools/CharacterPicker
